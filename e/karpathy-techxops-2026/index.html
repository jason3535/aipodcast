本期速览 · Overview

一位研究者讲述他从斯坦福到 OpenAI 和特斯拉的经历，并解释为什么随着神经网络作为新编程范式的兴起，黑客比以往任何时候都更令人兴奋。

A researcher recounts his path from Stanford to OpenAI and Tesla, and explains why hacking is more exciting than ever with the rise of neural networks as a new programming paradigm.

要点 · TL;DR

  • 神经网络实现了软件 2.0，通过数据而非代码进行编程。
    Neural networks enable Software 2.0, programming via data instead of code.
  • 英语是大型语言模型最热门的编程语言。
    English is the hottest programming language for large language models.
  • Transformer 是一种通用、高效、可通过提示重配置的计算机。
    Transformers are a universal, efficient computer reconfigurable via prompts.

核心观点 · Key points

  • 神经网络代表了一种新的编程范式，称为软件 2.0，通过积累数据集并迭代来编程。
    Neural networks represent a new programming paradigm called Software 2.0, where you program by accumulating datasets and iterating on them.
  • 最热门的新编程语言是英语，因为可以通过自然语言提示来编程大型语言模型。
    The hottest new programming language is English, as large language models can be programmed via natural language prompts.
  • Transformer 是一种通用、高效、可优化的计算机，可在运行时重新配置以运行自然语言程序。
    Transformers are a general-purpose, efficient, optimizable computer that can be reconfigured at runtime to run natural language programs.
  • 注意力机制是 Transformer 的通信阶段，节点通过有向图上的消息传递交换信息。
    Attention is the communication phase of the transformer, where nodes exchange information via message passing on directed graphs.
  • Transformer 架构已被证明具有极强的韧性，大多数现代模型仍基于 2017 年的设计。
    The transformer architecture has proven remarkably resilient, with most modern models still based on the 2017 design.

反共识 · Contrarian takes

  • 提示工程是一份真正的工作，而编程 AI 的最佳方式是用英语设计有效的提示。
    Prompt engineering is a real job, and the best way to program AI is by designing effective prompts in English.
  • 大型语言模型可以仅通过提示模拟整个虚拟机和文件系统，而无需任何实际代码。
    Large language models can simulate entire virtual machines and file systems purely through prompting, without any actual code.
  • Transformer 的成功部分归功于其在 GPU 上的效率，而不仅仅是其表达性或可优化性。
    The transformer's success is partly due to its efficiency on GPUs, not just its expressiveness or optimizability.
  • 大脑可能正在收敛到一种统一的学习算法，类似于 Transformer 在不同领域的应用。
    The brain may be converging to a uniform learning algorithm, similar to how transformers are used across different domains.
  • 软件 3.0 涉及通过提示来调节大型语言模型，这也是人类被编程的方式。
    Software 3.0 involves conditioning large language models via prompts, which is also how humans are programmed.
