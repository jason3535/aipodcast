本期速览 · Overview

Claude Design 与 Claude Motion 背后的设计师 Nate，分享如何通过提供上下文、代码库和大量方案选项，让 Claude 产出原创而非千篇一律的设计。

Nate, the designer behind Claude Design and Claude Motion, shares how he gets original, non-generic designs out of Claude by feeding it context, codebases, and wide option sets.

要点 · TL;DR

  • 给 Claude 丰富的上下文和过往作品；要求大量选项，然后重新组合。
    Give Claude rich context and past work; ask for many options, then remix.
  • 代码是最便宜的材料；原型周期从一年缩短到几天。
    Code is the cheapest material; prototyping cycles shrank from a year to days.
  • 澄清问题让用户愉悦；告诉模型它的偏见和默认风格。
    Clarifying questions delight users; tell the model its biases and default styles.

核心观点 · Key points

  • 输入决定输出：设计前先给 Claude 丰富上下文、情绪板和过往作品。
    You get out what you put in: give Claude rich context, mood boards, and past work before designing.
  • 先要大量风格迥异的方案，再把喜欢的部分重组进下一轮。
    Ask for many wide-ranging options, then remix the best parts into new rounds.
  • 让 Claude 读代码库并在画布上重建；代码才是真相来源，而非静态设计文件。
    Read the codebase and recreate it on canvas; code is the source of truth, not static design files.
  • 先独立产品面快速迭代，找到产品市场契合后再合并回主产品。
    Iterate in a standalone surface first, then merge back into the main product once it fits.
  • 代码如今最廉价；原型周期从一年压缩到一两天。
    Code is now the cheapest thing; prototyping cycles compressed from a year to one or two days.
  • 动态图形已从惨不忍睹跨到还行；趋势显示会快速变好。
    Motion graphics crossed from hilariously bad to okay; trajectory suggests rapid improvement.

反共识 · Contrarian takes

  • 设计前问用户一堆澄清问题反而更受欢迎，与无摩擦设计教条相反。
    Asking users many clarifying questions upfront increases delight, contrary to frictionless design dogma.
  • 直接告诉模型自己的失败模式和默认字体配色；它根本不知道自己的偏好。
    Tell the model its own failure modes and default fonts/colors; it has no idea of its biases.
  • 模型以为人能同时看清一切；必须提示它放慢节奏、一次只聚焦一处。
    Models assume humans see everything at once; you must prompt for slow, single-focus pacing.
  • 是/否评估优于 1-5 分制；设计质量仍需人眼判断，而非模型打分。
    Yes/no evals beat 1-5 rubrics; design quality still needs human eyes, not model judges.
  • 品味与真实感可能始终属于人类；如今错别字反而成了人工创作的证明。
    Taste and authenticity may stay uniquely human; typos now signal proof of human work.
  • 一个长 Claude Code 线程加子智能体，胜过编排大量并行线程。
    One long Claude Code thread with sub-agents beats orchestrating many parallel threads.
