为什么 MCP 和工具调用已经过时：AI 的未来是直接与代码交互

Why MCP and Tools Are Obsolete: The Future of AI Is Direct Code Interaction

本期速览 · Overview

坦诚分享为什么 MCP 这类工具调用架构是多余的，以及一段因 2015 年 Karpathy 文章而创业失败、最终被 ChatGPT 验证的个人经历。

A candid take on why tool-calling architectures like MCP are unnecessary, and a personal story of how a 2015 Karpathy article led to a startup failure and eventual vindication with ChatGPT.

要点 · TL;DR

  • AI 模型应直接编写并运行代码,取代 MCP 和工具调用层。
    AI models should directly write and run code, replacing MCP and tool-calling layers.
  • 借助工业化模型工厂,小团队可将从训练到发布的周期压缩到数周。
    Small teams can compress training-to-launch cycles to weeks with industrialized model factories.
  • 强化学习是后训练的关键,扩展到万亿参数仍属必要。
    Reinforcement learning is key to post-training; scaling to trillion parameters is still needed.

核心观点 · Key points

  • 模型构建本质上是一门工程，主要在于改进数据和算力效率，而不是证明数学定理。
    Model building is fundamentally engineering, mostly improving data and compute efficiency rather than solving math theorems.
  • 开放研究与开放权重至关重要，让世界拥有众多独立的AI实验室，而不是被少数巨头垄断。
    Open research and open weights are vital so the world has many independent AI labs, not a handful of giants.
  • 强化学习是LLM能力最大的推动力；通过后训练塑造行为能带来巨大收益。
    Reinforcement learning is the biggest driver of large language model capabilities; behavior shaping through post-training creates huge gains.
  • 预训练远未终结；强化学习将更早介入训练，教导模型如何从网络数据中推理。
    Pre-training is far from solved; reinforcement learning will move earlier into training to teach models how to reason from web data.
  • 具备持久验证行为的小模型可以超越大得多的模型，因此我们能从现有规模中榨出更多性能。
    Persistent, self-verifying behavior can make smaller models outperform much larger ones, so we can squeeze far more from existing sizes.

反共识 · Contrarian takes

  • 像MCP这种工具调用层很愚蠢；模型应该直接在虚拟机里写代码，而不是调用几十个工具。
    Tool-call layers like MCP are stupid; models should just write code directly in a virtual machine instead of calling dozens of tools.
  • 世界应当拥有数百家基础模型公司；即使是前五名玩家也应为了人类选择这种结局。
    The world should have hundreds of foundation-model companies; even a top-five player should prefer that outcome for humanity.
  • 对大多数知识工作有用的模型规模峰值可能接近一万亿参数，而不是再大几个数量级。
    The peak of useful model size for most knowledge work may be near one trillion parameters, not several orders of magnitude larger.
  • 著名的DeepSeek廉价训练运行具有误导性；真正的成本在于此前的研发、数据和基础设施投入。
    The famous cheap DeepSeek training run is misleading; the real cost lies in years of R&D, data, and infrastructure before it.
  • 现在限制开源模型有害无益；过度谨慎会固化现有巨头并限制创新，如同禁止烟草广告反而巩固垄断。
    Restricting open-source models now is harmful; overcaution will entrench incumbents and limit innovation, like cigarette ad bans.
  • 蒸馏不是关键；从头快速端到端训练模型，比压缩一个庞大教师模型更能带来洞察。
    Distillation is not the secret; rapidly training models end-to-end from scratch teaches more than compressing a giant teacher.
