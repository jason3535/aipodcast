Lauren Tan joins a live Q&A to discuss Grok Bot 1.0's standout features, from shopping and meeting assistance to usage tips and webhooks.

要点 · TL;DR

  • 把 Grok Bot 当作能主动做事、调用工具的 AI 队友，而不只是聊天机器人。
    Treat Grok Bot as an AI teammate that takes initiative and uses tools, not just a chatbot.
  • 少建几个 bot，合并例行任务，用一个“幕僚长”bot 来统筹工作。
    Create few bots, consolidate routines, and use a chief-of-staff bot to orchestrate work.
  • 别把写作外包给 AI；写作就是思考，所以要自己写。
    Don't outsource writing to AI; writing is thinking, so write yourself.

核心观点 · Key points

  • Grok Bot 是 AI 队友而非聊天机器人；应以智能体式方式使用，让它主动行动并使用工具。
    Grok Bot is an AI teammate, not a chatbot; use it agentically to take initiative and use tools.
  • 把机器人当作工具或队友：少而精、合并冗余，并指定一个主机器人作为幕僚长。
    Treat bots like tools or teammates: create few, consolidate, and assign a primary bot as chief of staff.
  • 将 Grok Bot 作为 Cursor Cloud Agents 和编码工具链的编排器，以分离上下文并并行处理工作。
    Use Grok Bot as an orchestrator for Cursor Cloud Agents and coding harnesses to separate context and parallelize work.
  • 例行任务和大量上下文会消耗用量；合并例行任务、使用 webhook，并按机器人监控用量。
    Routines and heavy context consume usage; consolidate routines, use webhooks, and monitor usage by bot.
  • 写作即思考；不要把沟通外包给 AI，用机器人获取信息但自己动笔。
    Writing is thinking; do not outsource communication to AI, use bots for information but write yourself.
  • 要敢于雄心：问自己哪些事可以交给机器人做，并自动化枯燥的衔接工作。
    Be ambitious: ask what you personally do that a bot could do instead, and automate the boring glue work.

反共识 · Contrarian takes

  • 你不需要几十个机器人；一个或少数设计良好的机器人就能完成大部分工作。
    You do not need dozens of bots; one or a few well-designed bots can get most work done.
  • 避免每隔几分钟运行例行任务；频繁定时唤醒浪费 token，是反模式。
    Avoid running routines every few minutes; frequent scheduled wake-ups waste tokens and are an anti-pattern.
  • 仅把 Grok Bot 当聊天机器人会浪费大部分能力；它应像个人助理一样行动。
    Using Grok Bot merely as a chatbot leaves most capabilities on the table; it should act like a personal assistant.
  • 绝不要把敏感信息粘贴到聊天中；使用保险库，因为聊天对机密并不安全。
    Never paste sensitive information into chat; use the vault, since chat is not secure for secrets.
  • 为保持长期一致性，把技能移出上下文窗口，放入 GitHub 等版本控制文件。
    For long-term consistency, move skills out of the context window into version-controlled files like GitHub.
  • 由 Grok Bot 编排时，编码工具链非常适合视频编辑等复杂的非编码工作。
    Coding harnesses are excellent for complex non-coding work like video editing when orchestrated by Grok Bot.
